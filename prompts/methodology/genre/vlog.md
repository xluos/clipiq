# Vlog 类型方法论

适用：日常 / 生活 / 旅行 / 工作 vlog。情绪线优先于信息线，BGM 主导节奏。

---

## 规则

### R-VLOG-001 情绪锚点优先
- category: structure
- when: 整片
- hit: 全片有 2-3 个清晰的情绪锚点（最开心 / 最累 / 最感动 / 最尴尬）
- violation: 全程同一情绪基调，无起伏
- fix: 用素材重排，把最强情绪片段分散在前中后

### R-VLOG-002 主角视角一致
- category: structure
- when: 整片
- hit: 旁白 / 字幕 / 镜头都贴近第一人称视角
- violation: 突然切到第三人称解说 / 像广告片
- fix: 统一回第一人称叙事

### R-VLOG-003 "两短一长"镜头节奏
- category: pacing
- when: 整片
- hit: 镜头编排出现明显的"两短一长"或"多短一长"——近景 / 特写短，全景 / 远景长
- violation: 全部特写或全部远景，无层次
- fix: 重排镜头景别次序

### R-VLOG-004 片段时长均衡
- category: pacing
- when: 整片
- hit: 不同地点 / 不同场景的片段时长基本均衡（差异 < 3x）
- violation: 某场景占 > 40% 片长，其它一笔带过
- fix: 减少冗长场景，补足短场景

### R-VLOG-005 BGM 情绪同步
- category: sound
- when: 整片
- hit: BGM 切换与情绪 / 场景切换同步，BGM 风格服务情绪
- violation: 一首 BGM 从头到尾，或 BGM 风格与画面情绪冲突
- fix: 按情绪段切换 BGM 或调整音量曲线

### R-VLOG-006 开头不要自我介绍
- category: hook
- when: 0-5s
- violation: "Hello 大家好我是 XX 今天是我 vlog 第几天" 这类铺垫
- fix: 直接进入今天最有反差 / 最有趣的画面，自我介绍可放字幕

### R-VLOG-007 收尾情绪落点
- category: completion
- when: 最后 10-15s
- hit: 有明确情绪收束（金句 / 远景 / 慢镜头 / 静止帧）
- violation: 突然黑屏 / 突然 CTA 没情绪过渡
- fix: 加 5s 情绪缓冲再 CTA

### R-VLOG-008 时长甜区
- category: completion
- when: 整片
- hit: 5-15 分钟（长 vlog）或 30s-90s（短 vlog）
- violation: 短 vlog 拖到 3-5 分钟 / 长 vlog 注水到 25 分钟
- fix: 删冗余 b-roll，让时长服务内容
