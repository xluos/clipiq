# 短剧 / 剧情类方法论

适用：短剧、剧情段子、情景演绎、带货剧情。高密度钩子 + 多反转。

---

## 规则

### R-DRAMA-001 0-3s 冲突开场
- category: hook
- when: 0-3s
- hit: 直接开场进入冲突 / 反差 / 戏剧情境（吵架 / 反转 / 异常画面）
- violation: 开场是平静日常 / 介绍人物 / 环境铺垫
- fix: 把最戏剧化的场景剪到开头

### R-DRAMA-002 钩子密度
- category: engagement
- when: 整片
- hit: 每 15-30s 至少一次反转 / 信息揭示 / 新冲突
- violation: 一个冲突拉长全片，无递进
- fix: 拆分冲突，加新反转节点

### R-DRAMA-003 角色立得住
- category: structure
- when: 前 15s
- hit: 主要角色身份 / 关系 / 立场在 15s 内交代清楚
- violation: 关系混乱观众分不清谁是谁
- fix: 加字幕标注关系 / 加身份证据镜头

### R-DRAMA-004 镜头快剪
- category: pacing
- when: 整片
- hit: 平均镜头时长 1-2s，对话段反打镜头快切
- violation: 长镜头跟拍多，无戏剧张力
- fix: 加快切节奏

### R-DRAMA-005 高潮反转位置
- category: structure
- when: 视频 70-85% 位置
- hit: 在视频 70-85% 位置有最大反转 / 真相揭示
- violation: 反转太早（前半段已揭晓后续平淡）或太晚（结尾没消化时间）
- fix: 重排剧情节奏，最大反转放在 70-85%

### R-DRAMA-006 字幕承担信息
- category: density
- when: 整片
- hit: 关键台词 / 心声 / 旁白用字幕强化（短剧用户常静音观看）
- violation: 关键信息仅靠对白，无字幕
- fix: 加字幕

### R-DRAMA-007 结尾钩下一集
- category: completion
- when: 最后 5s
- hit: 留悬念 / 抛新冲突 / 反转未完，引导看下一集
- violation: 故事完整结束无续集钩
- fix: 加一个 3-5s 悬念尾

### R-DRAMA-008 情绪烈度
- category: density
- when: 整片
- hit: 情绪表演有明显烈度（夸张表情 / 强语气 / 强冲突），符合短剧调性
- violation: 表演过于平淡像独立电影
- fix: 选取更高烈度的表演片段
