# 风景 / 旅拍方法论

适用：旅行 vlog、风景短片、城市漫游、自然纪录类。意境优先于信息，BGM 节拍主导剪辑。

---

## 规则

### R-TRAVEL-001 大景开场
- category: hook
- when: 0-5s
- hit: 用大全景 / 航拍 / 标志性地标开场，建立空间认知
- violation: 开场是脸部 / 室内 / 模糊近景，无地理识别度
- fix: 替换开场为目的地最有辨识度的画面

### R-TRAVEL-002 景别梯度
- category: structure
- when: 整片
- hit: 出现远景 → 全景 → 中景 → 近景 → 特写的梯度（不必严格顺序，但有层次）
- violation: 全程同一景别（全是航拍或全是脸部）
- fix: 补缺失景别的镜头

### R-TRAVEL-003 长短镜头交替
- category: pacing
- when: 整片
- hit: 长镜头 4-8s 铺意境 + 短镜头 1-2s 串组动作 / 细节
- violation: 全部长镜头变 PPT / 全部短镜头变 MV 混乱
- fix: 重新交替编排

### R-TRAVEL-004 BGM 节拍剪辑
- category: sound
- when: 整片
- hit: 主要切点落在 BGM 节拍 / 鼓点 / 副歌起拍
- violation: 切点与音乐脱节
- fix: 用节拍标尺重对齐切点

### R-TRAVEL-005 匹配剪辑过渡
- category: pacing
- when: 转场
- hit: 出现匹配剪辑（动作匹配 / 形状匹配 / 颜色匹配），过渡丝滑
- violation: 大量硬切或炫技转场拼凑
- fix: 用匹配剪辑替代部分硬切

### R-TRAVEL-006 情绪锚点
- category: structure
- when: 整片
- hit: 出现 1-2 个明确的情绪高点（如日出 / 山顶 / 古迹合影 / 慢镜抒情段）
- violation: 平淡走流水账
- fix: 把素材中最有情绪冲击的片段放在情绪节点位置

### R-TRAVEL-007 人物存在感
- category: structure
- when: 整片（旅拍）
- hit: 有人物入画建立代入感（背影 / 互动 / 第一视角）
- violation: 全程空景无主体，像景区宣传片
- fix: 加入主角入画的镜头

### R-TRAVEL-008 调色统一
- category: visual
- when: 整片
- hit: 全片调色风格统一（如统一冷色 / 统一胶片感）
- violation: 不同片段色调跳跃明显（手机直出混入相机 LOG）
- fix: 二次调色统一

### R-TRAVEL-009 时长甜区
- category: completion
- when: 整片
- hit: 短旅拍 30-90s / 中长旅拍 3-8 分钟
- violation: 旅拍超过 12 分钟容易拖沓
- fix: 精剪到甜区
