# 纪录片方法论

适用：人物纪录、事件纪录、深度专题、品牌纪录。情绪曲线优先于信息密度，章节感强。

---

## 规则

### R-DOC-001 三幕叙事
- category: structure
- when: 整片
- hit: Setup（介绍人物 / 背景）→ Confrontation（冲突 / 转折 / 挑战）→ Resolution（结局 / 升华）三幕清晰
- violation: 缺冲突或缺结局，结构松散
- fix: 重剪，明确每幕起止时间点

### R-DOC-002 主角 / 主题清晰
- category: structure
- when: 前 30s-2min
- hit: 观众在前 2 分钟能明确这是关于谁 / 关于什么的故事
- violation: 看完 5 分钟还不知道主角是谁
- fix: 把主角介绍 / 主题陈述前置

### R-DOC-003 情绪锚点
- category: structure
- when: 整片
- hit: 出现 2-3 个明确的情绪高点（流泪 / 突破 / 痛苦 / 顿悟）
- violation: 平淡叙述，无情绪冲击
- fix: 把素材中最强情绪片段放在三幕节点上

### R-DOC-004 动静镜头对比
- category: pacing
- when: 整片
- hit: 抒情段长镜头铺情绪 + 冲突段短镜头快剪强化张力
- violation: 全程一致节奏
- fix: 按情绪类型调整镜头时长

### R-DOC-005 空镜过渡
- category: pacing
- when: 章节切换 / 时间跳转
- hit: 用空镜 / 环境镜头 / 象征镜头作为过渡，给情绪缓冲
- violation: 硬切跳跃，观众跟不上
- fix: 插入 3-5s 空镜过渡

### R-DOC-006 多视角叙事
- category: structure
- when: 整片
- hit: 出现多个视角（主角 / 旁观者 / 第三方专家 / 资料档案）
- violation: 全程单一视角
- fix: 补访谈 / 资料 / 旁观视角片段

### R-DOC-007 声音设计层次
- category: sound
- when: 整片
- hit: 同期声 + 旁白 + 环境声 + BGM 有层次，不互相盖
- violation: BGM 盖住对话 / 环境声单一
- fix: 调整音轨平衡，关键对话静音其他轨

### R-DOC-008 时间结构选择
- category: structure
- when: 整片
- hit: 时间结构有意识选择（线性 / 倒叙 / 平行 / 环形），且服务于情绪
- violation: 时间线混乱无章法
- fix: 用倒叙抛悬念 / 用平行做对比，重新组织时间线

### R-DOC-009 结尾留白
- category: completion
- when: 最后 1-3 分钟
- hit: 有明确观点收束 + 留白 / 开放性思考
- violation: 突然结束 / 强行总结教化
- fix: 加情绪缓冲段 + 一句作者立场
