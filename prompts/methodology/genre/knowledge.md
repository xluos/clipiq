# 知识科普方法论

适用：科普讲解、视频论文（video essay）、行业分析、深度解读。强调论证链 + 情绪曲线。

---

## 规则

### R-KNOW-001 论点前置
- category: hook
- when: 0-30s
- hit: 30 秒内明确抛出本期核心论点 / 结论 / 问题
- violation: 30 秒还在讲背景 / 历史 / 闲谈
- fix: 把论点 / 结论提到开头，背景放到第二段

### R-KNOW-002 反常识钩
- category: hook
- when: 0-15s
- hit: 抛出反直觉 / 反常识陈述（"其实你以为的 X 是错的"）
- violation: 开头是教科书式定义
- fix: 找出本期最反直觉的点作为开头

### R-KNOW-003 论证链清晰
- category: structure
- when: 整片
- hit: 论点 → 证据 → 推理 → 结论 的链路清晰可追
- violation: 直接给结论，无中间推理
- fix: 补齐推理步骤

### R-KNOW-004 视觉化抽象概念
- category: density
- when: 涉及抽象概念时
- hit: 用图表 / 动画 / 类比 / 实体演示把抽象概念具象化
- violation: 全程口播 + 抽象文字
- fix: 加配图 / 动画 / 类比

### R-KNOW-005 信息密度峰值在第一段
- category: density
- when: 视频前 1/3
- hit: 最干的论点 / 数据放在前 1/3，后面是展开 / 论证
- violation: 干货堆在结尾观众已经流失
- fix: 重排素材，最强论点前置

### R-KNOW-006 情绪曲线
- category: structure
- when: 整片
- hit: 论证过程中有情绪起伏（惊讶 / 反思 / 感慨），不是纯理性平铺
- violation: 全程冷静讲述，无情绪
- fix: 用 BGM 起伏 / 镜头节奏 / 旁白语气制造情绪

### R-KNOW-007 章节化（中长视频）
- category: structure
- when: 整片 > 6 分钟
- hit: 论点拆分为 2-4 个子论点 / 章节，每章可独立成段
- violation: 一条直线讲到底
- fix: 重排为多个并列子论点

### R-KNOW-008 结尾观点升华 / 留白
- category: completion
- when: 最后 1-2 分钟
- hit: 不止总结，还有作者观点 / 开放性思考 / 留白
- violation: 仅复述论点
- fix: 加一句作者立场 / 反问 / 哲思
