# 教程 / Tutorial 方法论

适用：DIY、做菜、软件教学、技能演示。Deliberate pacing（刻意慢），强调可重看、可跟做。

---

## 规则

### R-TUTORIAL-001 成品前置
- category: hook
- when: 0-5s
- hit: 开头展示成品 / 最终效果，告诉观众"学完能做出什么"
- violation: 开头直接进入步骤，看不到目标
- fix: 加一个 3s 成品展示作为钩子

### R-TUTORIAL-002 步骤可枚举
- category: structure
- when: 整片
- hit: 步骤明确编号（Step 1 / Step 2...）或有可视化进度条
- violation: 步骤模糊连续，观众跟不上节奏
- fix: 加 step 字幕 / 序号 / 进度条

### R-TUTORIAL-003 准备清单
- category: structure
- when: 教程开始前
- hit: 列出所需材料 / 工具 / 前置条件
- violation: 边做边发现"还需要 XX"
- fix: 在开头 / 简介 / 字幕中列清单

### R-TUTORIAL-004 Deliberate pacing
- category: pacing
- when: 关键步骤
- hit: 关键步骤用长镜头 + 慢速展示（甚至 0.5× 慢动作）
- violation: 关键步骤一闪而过
- fix: 把关键步骤剪到 3-5s 并慢放

### R-TUTORIAL-005 错误演示
- category: density
- when: 整片
- hit: 出现"常见错误"或"踩坑提醒"
- violation: 全程正面演示，无避坑指引
- fix: 加一段错误对照

### R-TUTORIAL-006 文字 overlay 必需
- category: density
- when: 关键操作
- hit: 关键参数 / 快捷键 / 数值有文字 overlay 强化
- violation: 仅口头说出，无文字
- fix: 加字幕重点标注

### R-TUTORIAL-007 章节可跳读
- category: engagement
- when: 中长教程
- hit: 章节明确可跳读，每章首有 1 句 recap、章尾有 1 句总结
- violation: 强线性依赖，跳读看不懂
- fix: 章节首尾加 recap / summary 字幕

### R-TUTORIAL-008 结尾回顾
- category: completion
- when: 最后 15-30s
- hit: 完整复盘所有步骤 / 展示最终成品 / 提示常见变体
- violation: 做完最后一步就结束
- fix: 加复盘段
