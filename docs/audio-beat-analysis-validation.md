# BGM 节拍分析验证

## 当前链路

Studio 选择本地音频后，Electron main 执行以下确定性链路：

1. FFmpeg 将来源音频限制到当前粗剪时长，解码为 `16 kHz / mono / f32le`。
2. `energy-onset-v1` 计算局部能量起音、周期自相关、节拍相位和 BPM。
3. 分析结果以 `AudioBeatAnalysis` 写入 `EditPlan` 的 `music` 音轨。
4. 只为距离不超过 `150 ms` 的硬切边界生成 `BeatSyncSuggestion`。
5. 添加、替换和移除 BGM 都生成新的 `EditPlan revision` 与反馈事件；镜头调整后重新计算建议。
6. FFmpeg 代理预览复用已有 music 混音、淡入淡出和旁白 ducking。

低置信度、音频过短、没有稳定周期或只有叠化边界时不生成卡点建议。当前建议不会自动修改镜头、对白或字幕时间。

## 固定信号验证

## 自动化覆盖

- PCM 解码参数与 f32le 解析。
- `120 BPM` 固定点击音恢复。
- 静音与低证据降级。
- 卡点容差、叠化过滤和无副作用建议。
- BGM 添加/移除产生新版本。
- 镜头缩短后卡点建议自动刷新。
- 越界、乱序、过期的节拍证据被 `EditPlan` 校验拒绝。
