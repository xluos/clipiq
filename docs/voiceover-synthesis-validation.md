# 旁白修改与局部重合成验证

## 当前链路

1. Vlog Planner 可输出最多三段 `{ afterShotId, text }`，只能引用已选择且不是最后一个的 Shot。
2. 编译器把旁白锚定到后续真实视频片段，写入 `AudioClip.anchorClipId`，不接受模型生成的路径或时间线坐标。
3. Studio 可按镜头添加、修改、合成和移除旁白。
4. Electron 使用 macOS `say` 生成 `48 kHz / mono / PCM WAV`，用 `ffprobe` 校验真实时长。
5. 合成产物按文本、音色和语速生成稳定摘要；同一输入复用已有文件，修改文本只产生新的旁白文件和 `EditPlan revision`。
6. 镜头重排时旁白跟随 `anchorClipId` 更新；锚定镜头被删除时对应旁白一并移除。
7. 旁白时长超过锚定镜头时拒绝写入，避免截断语句或覆盖后续内容。
8. 文本旁白尚未合成时，代理预览跳过该段并写入 warning，不阻断画面、原声和字幕预览。

当前合成器是可替换的运行时边界，首个实现使用 macOS 系统音色。非 macOS 环境会返回明确的能力错误，不伪造音频文件。

## Studio 交互验证

在 `1728 × 968` 的浏览器预览中，用完整 Electron API 夹具验证：

- 合成失败后保留输入文本和编辑态，并显示可重试错误。
- 成功合成后显示旁白文本、`已合成` 和 `改旁白`。
- 修改文本后可重新合成，并生成可撤销的 `EditPlan revision`。
- 移除后恢复 `加旁白`，三栏布局保持完整。
- 当前页面没有控制台错误。

浏览器夹具只验证 UI 状态；真实音频文件、时长和缓存以本页的运行时验证结果为准。

## 自动化覆盖

- 系统音色列表解析和普通话音色选择。
- `say` 参数不经过 shell，固定输出 48 kHz PCM WAV。
- `ffprobe` 时长解析和无效时长拒绝。
- 文本、音色、语速变化使缓存摘要失效。
- Planner 旁白引用、数量和末尾锚点校验。
- 编译后旁白锚定真实视频片段。
- 已合成旁白的新增、重排跟随、移除和不可变 revision。
- 未合成旁白的代理预览降级 warning。
